# Machine Learning for Fraud Detection in High-Volume Transactional Systems

**A Cost-Sensitive Evaluation of Supervised and Unsupervised Approaches with Explainable AI**

*MSc Business Analytics Dissertation, Queen's University Belfast — in progress, expected September 2026*

## Status
This dissertation is currently in progress. This page will be updated with the full methodology, results and findings on completion. A summary is provided below based on the approved research proposal.

## Aim
To develop and evaluate a data-driven machine learning framework for fraud detection in high-volume transactional systems that balances predictive performance, operational relevance and interpretability.

## Research Questions
1. How effectively can anomaly detection identify fraudulent behaviour?
2. How do supervised and unsupervised approaches compare in this context?
3. What is the cost-benefit trade-off across different detection thresholds?
4. How can explainability improve the practical adoption of these models?

## Relevance
This work builds directly on techniques explored in my [Star Emergence imbalanced classification project](../star-emergence-imbalanced-classification) — applying the same class-imbalance and threshold-tuning principles to the higher-stakes context of financial fraud, with the addition of a cost-sensitive evaluation framework and explainable AI (XAI) to support real-world adoption by risk and compliance teams.
